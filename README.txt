# Spin & Learn — Netlify Classroom App

A zero-install, browser-based classroom student picker.

## Features
- Spin wheel and mystery-card student selection
- Class selection (Class 9, Class 10, My Class) and add-your-own class
- Pass option with supportive feedback
- Star points / participation tracker
- Team Challenge with random teams and team points
- No-repeat round: students are selected once before the picker starts a fresh round
- Saves class lists and scores in the browser's local storage
- Responsive on mobile and desktop; no backend or dependencies

## Deploy to Netlify
1. Extract `spin-learn-netlify.zip`.
2. Open Netlify and sign in.
3. Choose **Add new site → Deploy manually** (or drag-and-drop deploy).
4. Drag the extracted folder containing `index.html` into the deploy area.
5. Open the generated Netlify URL.

No build command, framework, package installation, or server is required.

## Important
Data is saved in the browser on the device used. It does not automatically sync between different phones or computers. Keep a backup copy of your class lists if needed.

## Edit student names
Choose a class, replace the names in the Student list box (one name per line), then press **Save names**.
